# 0.9.5 开合与玻璃稳定性审查

| Before | After | Why |
| --- | --- | --- |
| vShow 立即切换外壳高度，只有内容淡入 | 单个 body 裁剪区域从当前高度过渡，独立绝对定位玻璃自动跟随 | 开合有真实中间外形，文字保持原尺寸 |
| 切页时模糊 20→12→20px，折射边缘隐藏后恢复 | 同一玻璃层、模糊值与折射边缘持续存在 | 避免材质突变产生闪烁 |
| 改变尺寸时更新位移图与 feImage href | 一次生成 384×384 标准化图，图像尺寸为百分比 | 减少重绘和图像重新载入 |
| SVG 资源准备时立即启用 | Image.decode 后给 SVG 两帧预热，再接入 CSS | 避免首次使用空资源；失败保留 CSS 玻璃 |
| 在同步监听中 nextTick 可能先于组件更新队列 | pre 监听捕获旧尺寸，等待当前刷新结束读取目标尺寸 | 避免误认尺寸相同而跳过动画 |
| 尺寸动画期间直接锁定拖动框 | 先结束尺寸动画，再测量与冻结拖动框 | 避免拖动锁在半开大小 |

**Approve。** `panel-motion.js` 的尺寸动画采用技能 card-resize 配方允许的高度过渡：只有受限内容视口改变高度，固定宽度的内容不缩放，玻璃背景由其自然几何决定。它会产生少量布局；该取舍保留正常圆角、边框、阴影与模糊，并使裁剪和背景处于同一渲染时序。移动反馈继续使用 transform/opacity；拖动仍为按帧合并的 transform。

展开 220 毫秒、收起 180 毫秒、页签 140 毫秒，曲线为 `cubic-bezier(.22,1,.36,1)`。快速反向采样当前可见高度，旧回调不能清除新组；结束、取消、失焦、隐藏和卸载路径清理临时动画及样式。减少动态效果仅 80 毫秒透明度，不改变交互状态的更新时间。

567 项自动测试及桌面/320 像素真实 Edge 检查覆盖连续外形、最终状态、快速反向、输入焦点、触摸及玻璃身份稳定性。PNG 实帧用于目视圆角和底边，固定背景头部边缘像素差为补充检查。首次的缩放圆角变形与混合渲染时序下内容越界均通过录帧发现并修复，最终记录仅绑定交付候选。

详见 `tests/verification-0.9.5.log` 与 `tests/verification-0.9.5-browser.log`。无头软件渲染、录帧耗时与触摸模拟不等于物理设备固定帧率或触屏测试。
