# 第三方资源

扩展不从 CDN 加载可执行代码。以下指定版本随安装包分发，完整许可文本位于 `vendor/LICENSE-*.txt`；来源与 SHA256 见 `vendor/lock.json`。

| 资源 | 版本 | 许可 | 来源 |
| --- | --- | --- | --- |
| Vue runtime | 3.4.31 | MIT | https://github.com/vuejs/core |
| Vue Demi | 0.14.7 | MIT | https://github.com/vueuse/vue-demi |
| Element Plus JS / CSS | 2.7.2 | MIT | https://github.com/element-plus/element-plus |
| Element Plus Shadow CSS | 2.8.2 | MIT | https://github.com/element-plus/element-plus |
| Pinia | 2.3.1 | MIT | https://github.com/vuejs/pinia |
| RxJS | 7.8.2 | Apache-2.0 | https://github.com/ReactiveX/rxjs |
| blueimp MD5 | 2.19.0 | MIT | https://github.com/blueimp/JavaScript-MD5 |

超星字体映射数据沿用原脚本资源 `https://www.forestpolice.org/ttf/2.0/table.json`，随包保存为 `vendor/font-table.json`，只在识别到题目字体编码时使用。本项目未发现该数据单独提供的许可声明，不将其宣称为本项目原创或 MIT 授权。

模板中包含 Element Plus Icons Vue 2.3.2 的内联 SVG 路径（MIT，https://github.com/element-plus/element-plus-icons）。扩展图标由本项目的书本轮廓绘制。
