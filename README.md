# AI 网课学习助手

适用于超星学习通、智慧树的浏览器用户脚本，支持通过 OpenAI、DeepSeek 或兼容接口解答文字及图片题，并尝试填写网页答案。

当前版本：**0.8.0**。

[安装脚本](https://raw.githubusercontent.com/aides-hik/ai-course-helper/main/ai-course-helper.user.js) · [详细使用说明](使用说明.md) · [更新记录](修复说明.md)

## 安装和使用

1. 在浏览器中安装 Tampermonkey（油猴）扩展。
2. 点击上方「安装脚本」，按油猴提示安装。若浏览器只显示代码，可新建油猴脚本，将 [ai-course-helper.user.js](ai-course-helper.user.js) 的全部内容复制进去并保存。
3. 停用其他会操作同一学习页面的网课脚本，进入超星或智慧树的题目页面，打开悬浮面板的「解题」页签。
4. 选择 OpenAI 或 DeepSeek，确认请求地址，填写对应的 API Key，点击「获取模型」后选择模型，也可以手动填写模型名称。
5. 在「解题偏好」选择思考程度，按需开启并发答题，点击底部固定的「保存并刷新」。模型列表地址位于「模型列表与接口设置」，超时及输出上限也可展开调整。

升级时安装新版脚本，或用新版全部代码替换油猴中的旧内容，保存后刷新所有已打开的学习页面。地址、密钥、模型和思考程度按服务分别保存。

## 主要功能

- **文字题与图片题**：支持单选、多选、判断、填空和简答，读取题干及选项中的图片，包括纯图片选项。
- **两种接口模式**：OpenAI 使用 Responses 格式，DeepSeek 使用 Chat Completions 格式，可配置兼容接口的完整请求 URL。
- **一键获取模型**：读取当前地址的模型列表，保留手动填写入口，获取结果不会自动更换已选模型。
- **思考程度**：按服务分别设置，默认跟随模型；可用档位取决于所选模型和接口。
- **并发答题**：默认关闭，开启后同时解答当前页剩余题目，跳过已有作答；并发数可设为 1–2500，默认 3。
- **答案与状态展示**：显示模型答案、简短解析、token 用量及填写状态。
- **旧请求取消**：页面、题目或当前服务、密钥、模型、思考程度、解题 URL 变化时，取消过期请求并阻止旧答案回填。
- **学习概览与日志**：概览展示实际任务进度和当前状态，运行记录支持简要、详细切换；复制始终包含最近 500 条完整日志。章节诊断显示完成依据、视频进度和阻塞原因，资源地址省略参数。
- **整体液态玻璃界面**：外壳、页签、状态区、输入框及按钮采用统一玻璃层次。面板默认 396 像素并适配窄屏，配置保存按钮始终可见；收起、展开和页签切换有轻量反馈动画，支持减少动态效果。

[Figma 可编辑设计稿](https://www.figma.com/design/tM92ylAZ9DonRMdP1vE2Dq?node-id=4-75) 包含桌面概览、模型连接和窄屏布局，设计构建源及状态记录位于 `design/`。

## 模型和请求地址

使用官方服务时保留默认地址；使用兼容服务或本地服务时，在「解题请求 URL」填写完整接口路径。

| 面板模式 | 默认解题请求 URL | 默认模型列表 URL |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1/responses` | `https://api.openai.com/v1/models` |
| DeepSeek | `https://api.deepseek.com/chat/completions` | `https://api.deepseek.com/models` |

「模型列表 URL」留空时，将解题地址末尾的 `/responses` 或 `/chat/completions` 替换为 `/models`，保留路径前缀和查询参数。例如：

```text
解题请求：https://gateway.example/api/v1/responses
模型列表：https://gateway.example/api/v1/models
```

如果服务使用其他列表路径，展开「模型列表与接口设置」填写「模型列表 URL」。无法获取列表时，仍可手动填写模型名称。点击「恢复默认地址」只重置当前服务的两个地址。

地址支持 HTTP、HTTPS、本地地址和端口。**填写完整接口路径，不要只填域名或 `/v1`。** 修改 URL 后，请求格式仍由面板模式决定：OpenAI 模式需要兼容 Responses 和结构化输出，DeepSeek 模式需要兼容 Chat Completions 和 JSON 输出；图片题还要求接口及模型支持图片输入。

思考程度不确定时选「默认」。选择不支持的档位后，可恢复默认再尝试。模型列表可能包含不适合解题的模型，获取成功也不代表所选模型具备图片或思考能力。

## 并发和默认行为

并发只处理当前页面同时显示的题目。实际同时请求数取设定值和剩余未作答题数中的较小值。例如设置 2500，当前页 40 题中有 10 题已作答，就同时处理剩余 30 题。没有剩余题目时不发送请求。

已有选择的单选、多选、判断题会跳过；文字题须所有空都有内容才跳过。多选题已有一个选项也会视为已作答，需自行核对是否漏选。并发不会自动重试失败请求；出现限流时可降低并发数。

章节自动提交、自动下一章节、视频弹题自动处理及考试、智慧树自动切换默认关闭，可在「设置」中按需启用。启用视频弹题自动处理会提交弹题。

面板中的填写率表示已确认填写的比例，不代表答案正确率，提交前请核对。

## 图片与数据处理

支持网页 `<img>` 中的 PNG、JPEG、WebP、GIF，以及常见懒加载图片。每题最多 20 张图片；内嵌数据单张最多 8 MiB，合计最多 20 MiB。SVG、canvas、CSS 背景图和音视频暂需手动处理；图片无法读取或超出限制时会停止该题。

API Key 保存在脚本管理器的独立配置中。解题时，密钥、题目和图片会发送到当前配置的解题地址；获取模型时，密钥会发送到配置的模型列表地址。请使用可信服务并优先使用 HTTPS，费用由相应接口账户承担。

为支持自定义域名，脚本声明了 `@connect *`；向模型接口和模型列表接口发送的请求不携带学习平台 Cookie。脚本还会加载元数据中列出的界面库和字体映射资源。原题库、公告接口和原脚本自动更新地址已移除；后续升级需手动安装新版。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 获取模型失败 | 检查密钥、模型列表 URL、网络和油猴的域名访问权限；也可手动填写模型名 |
| 401 / 402 | 检查对应服务的密钥或账户余额 |
| 403 / 404 | 检查完整接口路径、模型名称和账户权限 |
| 429 或请求过慢 | 降低并发数，检查服务限流；必要时调整超时和输出上限 |
| 思考参数不被支持 | 将「思考程度」恢复为「默认」 |
| 图片无法读取或答案格式错误 | 按面板具体提示检查；无法确认的题目请手动处理 |
| 修改配置后没有重新解题 | 点击「保存并刷新」 |

反馈问题时，请附上脚本版本、平台页面类型和错误提示，不要附带 API Key。

## 源码和构建

安装直接使用仓库中的 `ai-course-helper.user.js`。从源码重新构建只需 Python 3，在项目根目录运行：

```sh
python build_ai.py
```

构建无需联网或 npm，会将模板与各模块合并成安装脚本。修改功能后应重新构建，保持安装文件与源码一致。

| 文件 | 用途 |
| --- | --- |
| `userscript.template.js.in` | 脚本元数据、配置面板和平台适配模板 |
| `ui-panel.css` | 悬浮面板与配置区域样式，构建时嵌入脚本 |
| `ai-adapter.js` | 模型请求、返回解析及答案校验 |
| `ai-endpoints.js` / `ai-models.js` | 请求地址解析与模型列表获取 |
| `ai-images.js` / `text-extraction.js` | 图片准备与题目内容提取 |
| `ai-integration.js` | 答题调度、并发、已有答案识别及填写 |
| `chapter-logic.js` / `exam-logic.js` / `page-hooks.js` | 章节、考试和页面事件处理 |
| `config-storage.js` | 脚本配置保存和同步 |
| `tests/` | 自动测试、浏览器测试及验证记录 |
